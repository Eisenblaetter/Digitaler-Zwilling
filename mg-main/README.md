# Main MontiGem Codebase

This is the main part of the digital twin, a full-stack web application generated by MontiGem. It contains an Angular frontend, a Spring Boot backend and PostgreSQL for the database.

## Useful commands

To build the application, you can run:
```bash
    gradle build
```

To run the entire application, you need to run the following two commands, in separate terminal windows:
```bash
    gradle :backend:run 
    gradle :frontend:run
```

If you only want to reload frontend code and not regenerate the entire codebase, you can run:
```bash
    gradle :frontend:sync_gui2java2ts
```

## Some notes/tweaks

- Depending on the Java version you might need to change the import in `backend/.../...ServerApplication.java` from `import javax.annotation.PostConstruct` to `import jakarta.annotation.PostConstruct`.
- On macOS, you need to install following homebrew packages in order for the build to complete successfully: 
    ```bash
        brew install pkg-config cairo pango libpng jpeg giflib librsvg
    ```
- Make sure Gradle is on version 8.14.4 and you are using JDK 21
